# 聚合规则(卡 → 结论强度推导 · 2026-08-24)

> 执行位:汇编综合环节,agent 按本规则自评并在 dossier 每条 claim 落 `rule_trace`;
> 规则外判断必须写 `override_reason`(dossier_check 机器强制);
> 独立复核 agent 专查「证据强度拔高」「虚假精确」(B 级证据写出 A 级口吻),判准即本文。
> 词表:四档 `strong / medium_strong / medium / weak`,中文渲染「强 / 中强 / 中 / 弱」。

## 推导规则

- **strong(强)**:≥3 个独立来源 + ≥1 个可核验的本地闭环样本 + 有可观察经营指标
- **medium_strong(中强)**:满足前两项,经营指标不完整
- **medium(中)**:独立来源仅 2 个,或本地闭环样本缺失;缺项必须注明
- **weak(弱)**:单一来源,或仅二手/仅声量支撑;缺项必须注明

## tier 折减

- B 级为主的主张,强度上限 **medium**(够不到 strong)
- A− 计入独立来源数,但 strong 至少含 1 个 A 级来源
- 「独立」= 数据生成方不同;同一集团/同一发布方的多篇算 1 个来源(防重复计数)

## 附注

- 「本地闭环样本」= 在研究对象地域/范围内可完整核验一遍的实例;跨任务复用时按项目口径重解释。
- 出处:本规则由本项目制定;强/中强两档沿用通行的学术审阅口径。
