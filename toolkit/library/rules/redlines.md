# 口径红线(通用版 · 2026-08-24)

⛔ **条数以下表为准,别在别处写死编号。**

> 性质:**推理卫生规则,方向中立**——禁止无效推理动作,不指定结论方向。
> 治理:默认继承进每个 task_plan(1c);偏离须在 task_plan 显式声明并过对接窗口1(D14 显式通道)。
> 执行位:独立复核 agent 检查表核心(验收指标「红线复现」的对照全集);机器窗口不硬拦本表。
> 生长:新项目落卡长出的新红线 → 汇编边界层 → 本库 candidate → 人审升格。

| # | 红线 | 防什么 |
|---|---|---|
| R1 | **统计口径不互换**:增加值 ≠ 总产值 ≠ 营业收入;GMV ≠ 收入;提货量/产量 ≠ 销售额/市场份额。不相加、不换算、不并列 | 跨口径相加造出不存在的总规模 |
| R2 | **行政/地理层级不混用**:全国 ≠ 省 ≠ 市 ≠ 区;外地产能/协同资源不写成本地基础;属地按注册地+主要经营地双核 | 层级混用夸大本地规模 |
| R3 | **主体层级不混用**:企业 ≠ 行业;集团 ≠ 品牌;控股 ≠ 业务归属;生态/关联 ≠ 直接拥有——间接关联主体的数据,须先核实权利与控制关系的具体分层(分层方式依领域而定)再谈归属 | 头部企业数据冒充行业趋势;关联数据错误归属 |
| R4 | **相邻品类/市场不互相冒充**:上游 ≠ 下游;母集 ≠ 子集,不相加、不互代——大口径数字不能证明子口径规模,反之亦然 | 相邻大数替代目标口径 |
| R5 | **名义 ≠ 实际**:名义增速未扣价格因素,不解释成数量增长 | 涨价被读成放量 |
| R6 | **预测/目标 ≠ 已实现**:预测值、规划目标、政策资助上限必须标属性 | 愿景写成现状 |
| R7 | **口径存疑不计算**:同一指标年度间口径未说明变化 → 不计算同比、不排名 | 断链数据造趋势 |
| R8 | **推算值 ≠ 官方发布**:反推/估算只能称「按公开口径计算的估计」 | 计算值冒充官方统计 |
| R9 | **平台指标不混用**:注册用户 ≠ 活跃买家 ≠ GMV;不同平台的同名指标定义不可直接横比 | 平台自报大数互相冒充 |
| R10 | **人才口径分开**:招生计划 ≠ 在校生 ≠ 毕业生 ≠ 从业者 ≠ 人才储备;外地/合作办学不并入本地 | 招生规模写成产业人才供给 |
| R11 | **外生冲击造成的价差 ≠ 关系性收益**:价差/折让幅度类主张必须与外生事件时间线对照检验(幅度收窄/走阔是否随事件节奏联动);无此检验,不得把价差写成双方关系或合作安排的产物 | 把外部环境变动造成的被迫让价写成关系带来的稳定收益 |
| R12 | **被动获得的让利 ≠ 主动掌握的议价权**:一方因交易对手处境受限而被动获得的价格好处,与一方凭资产所有权/定价权主动取得的收益,形成机制与可持续性相反,不得当作同一种「优势」跨时期或跨对象类比;要并列必须各自说明来源与存续条件 | 类比时把位置相反的两类优势(受益于对方弱势 vs 源于自身控制力)混为一谈 |
