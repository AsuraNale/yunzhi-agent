# 证据等级 A / A− / B(2026-08-24 · 全线统一)

**定义**:

> A ＝ 财报、监管文件、官方制度文件;A− ＝ 企业官方但未经独立审计的运营披露;B ＝ 行业协会或研究报告。数字不具可比性时不做横向排名。
> 集团数据不冒充品牌数据,地区数据不冒充全球数据。

**边界样例**(来源实测归纳):
- 算 **A**:经审计年报、政府正式发文、国际组织出版物、监管文件、交易所/IR 公告。
- 降 **A−**:发布主体权威但内容是自报/宣传口径(企业官网合作页、新闻稿、integrated report 自述)。
- 混合级(如「A/B+」)禁用:tier 取低值,细微差别写 note(card_check 强制)。

**统一规则**:
- 旧 A/B/C 体系映射:A→A;B→B;**C 类(政府转载媒体/企业案例/地方宣传)= B + 使用限制「只用于现象说明,不支撑规模结论」**,note 记原级。
- 「数值类主张须 A 级」**不立硬规则**;其目的由规格⑤(claims_source + unverified 角标)承接。
- tier 挂在**来源**上,卡不带等级;强度是汇编层产物(见 aggregation.md)。
