# 判读纪律 D1–D17(2026-08-24)

> 执行位:evidence-card / cite-trace skill 的 prose 层 + 独立复核 agent 检查表;D16/D17 已由规格字段机制化。

| # | 纪律 |
|---|---|
| D1 | **先卡后文**:落卡在采集/判读期;生成期只消费卡,写作中缺证据 → 停下补卡重过对接窗口2 |
| D2 | **一手优先**:有一手资料(财报、官方公告、行业报告)就用,不止步于二手报道 |
| D3 | **数值-口径成对**:facts = [(数值, 口径)],不许一坨数字共享一句口径 |
| D4 | **局限必填**:空卡不可被大纲引用;limits 自由文本不枚举化 |
| D5 | **空≠失败**:「数据不存在」本身立卡(stance: gap);采集五态如实记 |
| D6 | **反例显式纳入**:未按显式标准穷举纳入 → 降级称「边界案例」;反例贯穿全文不放结尾 |
| D7 | **拒绝伪精确**:强度只用封闭词表,不打分不百分制 |
| D8 | **卡号不作终点引用**;历史判读只作起点,弱/gap 卡引用前必须回源重验 |
| D9 | **不改旧卡 + 快照纪律**:更新走增量卡,旧卡逐字原样;截止日后发布的数据不提前使用 |
| D10 | **披露性质必标**:企业自报 ≠ 独立审计;非 GAAP ≠ GAAP;「疑似」≠ 认定 |
| D11 | **异常基期声明**:疫情年、特殊事件基数作基期须声明 |
| D12 | **归因纪律**:禁单因归因;同期发生 ≠ 因果;比较级主张需可比排名 |
| D13 | **代理指标 ≠ 目标构念**(如专利数 ≠ 设计能力) |
| D14 | **降级走显式通道**:放宽口径允许,但须 task_plan 写明 → 汇编复现 → 复核专查 → 归档带标 |
| D15 | **不强行证明**:先证前提再进下一段;证伪也是成果;判定「落在预注册空间内,或有书面修订记录」(严禁写成「必须落在空间内」) |
| D16 | **转引标注**(已机制化,规格⑤):B 级标 claims_source;无法回溯标 unverified 角标 |
| D17 | **as-of 强制**(已机制化,规格②):每卡带 as-of;历史卡缺失如实标注不回填 |
